# Python-Skripte: Beispielsammlung

Link zum Kurs: [Einführung in Python 2.7 anhand von Beispielen (2012)](https://stahe.github.io/de-python2.7-mars-2012/)

---

## 📌 Überblick

Dieses Projekt bietet eine Sammlung von Python-Skripten, die verschiedene technische Bereiche abdecken. Es handelt sich nicht um einen theoretischen Kurs, sondern um eine **Sammlung praktischer Beispiele**, die als schnelle Einführung gedacht ist.

### Behandelte Themen:

**Grundlagen** der Programmiersprache Python.

* Verwaltung von **MySQL**-Datenbanken.

* TCP/IP-Netzwerkprogrammierung

* **Web**-Programmierung.

* **Dreischichtige** Architekturen und **schnittstellenbasierte** Programmierung.

---

## 🎯 Zielgruppe

Dieses Dokument richtet sich an Entwickler, die bereits Erfahrung haben mit:

* Skriptsprachen (**Perl, PHP, VBScript**).
* Typisierten Sprachen (**Java, C#**) und die sich mit objektorientierter Programmierung in Python vertraut machen möchten.

> [!WICHTIG]
> Dieser Inhalt ist für absolute Programmieranfänger **ungeeignet**. Er soll nicht die absolut „besten Praktiken“ vermitteln; ein erfahrener Entwickler könnte den Code teilweise als optimierungsbedürftig ansehen.

## 📖 So nutzen Sie diese Sammlung

Um das Beste aus diesem Repository herauszuholen, ist **aktives Lesen** unerlässlich. Zu jedem Skript finden Sie:
* Kommentierten Quellcode.
* Eine Nachbildung der Konsolenausgabe.
* Zusätzliche Erläuterungen, wo nötig.
